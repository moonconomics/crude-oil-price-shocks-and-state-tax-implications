# crude-oil-price-shocks-and-state-tax-implications

This file provides guidelines to replicate all the empirical results found in this study. The replication files are available in the repository. The latter includes only one do file for all the codes, one R script file, and 16 excel files. The file named codes.do provides all the instructions to compute all the regressions, tables, and main figures listed in the paper. I used RStudio to scrape the dow Jones data. You can access the script file in the repository folder.
